# 生徒カルテ　配り物

教室の中で使う「生徒カルテ」の、実行ファイルだけを置く場所です。ソースと資料は、ここにはありません。

- 配り物は [Releases](../../releases) にあります。教室のPCの `karte.exe` は、起動のときに、ここのいちばん新しい版を確かめます。
- `manifest.json` は版の情報、`manifest.json.sig` はその署名、`karte-windows-amd64.exe` は実行ファイルです。
- `karte.exe` は、署名を確かめられた版の情報と、中身（SHA-256）が合う実行ファイルだけを取り込みます。
- 確かめのときに `karte.exe` が送るのは、いま動いている版の番号だけです。

ここに、生徒の情報、設定、鍵を置きません。
